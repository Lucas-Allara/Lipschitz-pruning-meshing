# Scenes

`trees.json`, `monument.json` and `molecule.json` come from the official repository of Lipschitz Pruning (github.com/wbrbr/LipschitzPruning, MIT). *Trees* and *Monument* are by Élie Michel (CC-BY 4.0); *Molecule* is from *Segment Tracing Using Local Lipschitz Bounds* (Galin et al., 2020); `monument.json` is stored without whitespace to stay under the GitHub size warning. The scenes in `synthetic/` are generated with `lpm_synth` (random spheres of radius 0.05, balanced union trees; `fluid_*` packs 5000 spheres in a box of side 0.5).
